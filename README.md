## What is this?

A complete collection of **883 DNB ENT theory exam questions and model answers** covering all four papers (2011–2025), written strictly from Scott-Brown's Otorhinolaryngology 8th Edition — the gold-standard reference for the DNB final examination.

Every answer is:
- Structured for **exam writing** (Introduction → Parts A/B/C → Key Points → Clinical Pearls)
- Referenced to the relevant chapter of Scott-Brown 8th Ed.
- Formatted with tables, flowcharts, and callout boxes
- Searchable and cross-linked via Obsidian-style wikilinks
